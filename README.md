
# 🍔 Food Delivery Analytics Dashboard

## 📌 Project Overview

This Power BI project analyzes food delivery business data and provides valuable insights into revenue, order performance, delivery efficiency, and restaurant operations.

The dashboard helps understand:

✔ Revenue Performance
✔ Order Analysis
✔ Delivery Efficiency
✔ Restaurant Comparison
✔ Delivery Status Monitoring

 📊 Dashboard Features

* **Total Revenue KPI** – Displays overall business revenue generated from orders
* **Order Count KPI** – Tracks the total number of orders
* **Average Delivery Time KPI** – Measures delivery performance efficiency
* **Revenue by Restaurant** – Compares restaurant-wise earnings
* **Delivery Time Analysis** – Evaluates delivery performance by restaurant
* **Delivery Status Distribution** – Shows Fast vs Late deliveries
* **Restaurant-wise Analysis** – Compares restaurant performance
* **Interactive Filters** – Restaurant selection for better insights
